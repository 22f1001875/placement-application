# Placement Portal Application – V2  
**Modern Application Development II**

---

## Overview

The Placement Portal Application – V2 is a full-stack web application developed as part of the *Modern Application Development II* course at IIT Madras.

The system streamlines the campus recruitment process by providing a centralized platform for students, recruiters, and administrators. It enables structured job postings, eligibility filtering, and application tracking through a secure role-based architecture.

This project demonstrates practical implementation of full-stack development concepts including RESTful API design, database modeling, authentication, and modular system architecture.
